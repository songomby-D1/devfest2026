# Malagasy cultural heritage platform

[CONFIRMED] This project for the **Preserving the Art** hackathon helps people discover, explore and understand Malagasy cultural heritage. It covers traditional craftsmanship and artistic techniques, paintings, sculptures, cultural objects and their authors, traditional music and multimedia, 3D representations, and digital provenance.

[NOT IMPLEMENTED] The repository is in pre-implementation. It contains documentation and placeholders. The frontend, gateway, services and tooling have yet to be initialized.
